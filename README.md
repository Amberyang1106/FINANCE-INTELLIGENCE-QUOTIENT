# FP&A Agent Demo

一个面向财务计划与分析团队的桌面工作台概念稿，结合 Pi 桌面客户端的会话体验和可扩展工作区思路。界面采用 Hallmark Cobalt 设计系统。

## 使用

直接用浏览器打开 `index.html`。

## 已实现的演示交互

- 监控台、分析任务、报告库三种视图切换
- 点击异常进入对应分析任务
- 证据、建议、情景测算标签切换
- 情景参数滑块和实时影响计算
- 新建分析、建议追问和发送反馈
- Cobalt 冷白纸面、Graphite 分析区、切角面板和 keycap 控件

该版本为前端交互 Demo，数据为演示数据，尚未连接真实财务系统或 Pi Agent 运行时。
