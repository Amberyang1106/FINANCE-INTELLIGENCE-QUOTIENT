# FP&A Agent 视频制作指南 v0.2 · 三分钟内版

日期：2026-10-29。配套：[产品介绍视频脚本](PRODUCT-VIDEO-SCRIPT.md)。

适用源版本：feature/vantage-ui / b5541d4；main 不合并。本指南是制作执行手册。本轮已进入制作交付，实际素材、工具与验收结果见 [制作报告](PRODUCTION-REPORT.md)。

## 1. 交付目标与制作路线

制作一条以 2 分 50 秒为目标、实际文件时长小于 3 分钟的 16:9 产品介绍主片，以真实 Vantage Demo 录屏呈现四条故事线。片头、转场、片尾和音频尾部均包含在总时长内。默认中文旁白、英文 UI、中文字幕。先确认脚本，再做录屏粗剪，随后录正式旁白、精剪、验收和导出。

路线：脚本锁定 → 演示状态准备 → 分段录屏 → 临时旁白/粗剪 → 正式旁白和字幕 → 精剪与混音 → 逐项验收 → 输出成片。

先复用已有录屏和剪辑工具，无需为了首片新建一套视频框架。后续若需要程序化剪辑，沿用同一镜头 ID、旁白和素材清单，工具选择在制作阶段再核实。

Sites 当前尚未部署；可以使用本地 Demo 制作初稿。需要在片尾放在线入口时，待实际 Sites 发布并验收后再加入真实地址。录屏原型与在线站点不是同一项交付，本轮不执行部署。

## 2. 画面与声音规格

以下为本片建议的制作参数，不代表已生成的文件规格。

| 项目 | 建议 |
| --- | --- |
| 主片画幅 | 1920 × 1080，16:9，30fps |
| 录制区域 | 浏览器网页内容区，保持固定尺寸；不录其他应用窗口或桌面 |
| 页面缩放 | 从 100% 开始试录，确保表格与右侧 Inspector 都可读；确定后全片统一 |
| 画面构成 | 全景说明位置，关键证据/数值使用局部放大；章节回到全景帮助定位 |
| 输出容器 | MP4，H.264 视频 + AAC 音频 |
| 字幕 | 中文字幕烧录版，同时保留可编辑的 SRT 与字幕文本 |
| 旁白 | 单独音轨录制，保留原始音频；清晰、平稳，英文缩写读法统一 |
| 音乐 | 可不使用；若使用，降低到不影响旁白辨识，避免强节拍盖住业务说明 |
| 静态图形 | 使用原 Vantage 字体/配色，中文沿用清晰的无衬线后备字体，原 Logo 不变形 |

先试录 10–15 秒，确认实际录屏尺寸和 1080p 播放时的文字可读性。当前工作台在宽屏有居中限宽：不要为了填满画面拉伸网页或 Logo。局部放大约 1.15–1.35 倍即可作为起点，放大后仍要保留必要的季度、Segment、币种或来源标题。

## 3. 准备可重复的录制环境

### 3.1 固定版本与页面

1. 确认当前为 feature/vantage-ui，源代码基线是 b5541d4 或在其上的已审阅版本，禁止切换/合并到 main。
2. 使用完整项目提供本地静态预览，保留本地字体、Logo、数据和依赖文件；仅复制 index.html 会缺少功能。
3. 当前 4175 为演示与 QA 环境，有历史问答、看板和 QA 任务。正式录制使用独立浏览器配置或独立本地端口，例如 4177，让同源存储与 4175 分离。记录中途保持同一端口、同一浏览器配置。
4. 不清除用户现有浏览器数据，不覆盖原方案、任务或 Sample 进度。
5. 网页中不要叠加调试面板；指针从画面边缘进入，不在关键数字上来回晃动。

本轮使用独立 4177 录制端口，保留用户 4175 环境；录制视口临时设为 1920 × 900，拍摄后恢复。

### 3.2 一次性准备清单

| 区域 | 拍摄开始前应有的状态 |
| --- | --- |
| Monitor | ROW / L0AUXG / 2026 Q3，Review period 为 2026009，排除情景未勾选 |
| Analysis | 尚未执行本次调查，提问与范围可由预警自动带入 |
| Actions | 主片使用联系入账人、核查正向凭证、核对 Segment 三项 |
| Scenario / Reports | 首次从原始状态录制，保存后沿用同一个 candidate，不中途重新保存成另一份 |
| Chat | 新建空对话；ISG Service；固定选择 MR Logic，避免个人笔记改变演示答案来源 |
| Knowledge | 内置 2 文件/11 卡；个人知识仅展示已有库或创建入口，无须为本片另录创建/编辑过程 |
| Studio | 尚未生成本次两张监控图；确认 ISG / ISG Service 范围，避免重复生成卡片 |
| Market | 保留三张内置模板与安装入口；本地个人集合可以为空，本片不展开安装/发布/导出 |
| Task To-do | 五个 Built-in samples 保留；Finance reviewer 视角；录新任务时切到 My proposal tasks |

镜头 07 固定选择 MR Logic，使规则回答来源可重复。个人知识库功能在镜头 08 点到为止，不占用额外录制与讲解时间。

### 3.3 重录与恢复

- 原生动效当前没有统一 Replay / Presentation mode；不要在脚本中要求点击尚不存在的按钮。
- 异常聚焦：Month 1 → Month 3 或重新进入 Monitor，可重新触发。对照原始范围后再录。
- 调查：新环境点击 Analyze negative GP；已完成的环境可重新提交同一问题，完整记录新一轮四步过程。
- 凭证：关闭后重新打开，字段强调再次播放。
- Scenario：取消 exclusion，再勾选，可重播对比强调；不要在切换中保存错误的情景版本。
- Studio：需要重录“首次生成”时，使用另一个已准备好的录制环境；不把重复生成的图表冒充首次结果。
- 任务：同一 proposal/行动重复创建会去重，已完成任务不能当作新任务倒放。需要重拍完整五阶段时，使用新的隔离环境并重新走创建流程。
- Reset demo 只清除原分摊方案与报告，不清空任务、知识库、对话或自定义看板，不能作为全产品重置按钮。
- 不手动改 localStorage 或伪造任务日志以追求画面整齐；使用真实操作得到的状态。

## 4. 录屏清单与拍摄顺序

剪辑顺序按脚本 01–14；为保护方案与任务的连续性，实际可以按下面的素材组拍摄。片头的界面预览从后续真实素材中抽取，不需要预先造状态。

| 素材组 | 对应镜头 | 录制内容 | 拍摄后保留 |
| --- | --- | --- | --- |
| A · 分摊调查 | 02–06 | Monitor、预警、四步分析、凭证、建议、Scenario、保存与报告 | 同一 saved proposal 与 report |
| D · 任务闭环 | 11–13 | 从 A 的报告创建一个行动，分派、接收、开始、填结果、完成和关窗跨列 | 任务快照和原五个 Sample 均保留 |
| B · 知识问答 | 07–08 | 新对话、MR Logic、流式片段、完整回答的引用、Files/Cards 和个人库入口 | 原问答与来源 |
| C · 自建监控 | 09–10 | GP 图/阈值、Revenue 趋势、一次拖动、Market 模板入口 | 两张监控卡，三张内置模板保留 |
| E · 包装素材 | 01、14 | 工作台全景、功能短预览、片头/片尾标题 | 不改变功能状态 |

A 和 D 先连续拍摄，后期把 B、C 插入两者之间；镜头 11 的“回到保存的方案”仍指向同一份方案。不要混入另一个 profit center、不同日期范围或不同 saved proposal 的截图。

每条素材以镜头 ID 命名，例如 S04_voucher_take01.mp4；取用片段写入剪辑备注，保留未加字幕/旁白的原素材。

## 5. 五项原生动效的录制方法

| 动效 | 需要留下的过程 | 录制建议 |
| --- | --- | --- |
| 异常聚焦 | 加载完成后 GA GP → LE Revenue → GA 预警，随后稳定 | 触发后至少保留约 3.5s；取景覆盖台账和预警，无法同屏时分录全景与局部，但不改变数据 |
| 调查步骤 | 四步约 4.4s；当前步骤与证据关联，结论随后出现 | 首次展示完整保留原速，不用快进暗示系统响应性能 |
| 凭证呈现 | 280ms 进入，金额/Segment/User/Reference/检查结论依次强调 | 保留约 2–3s；再用慢滚动展示 Positive-entry check 的范围说明 |
| Scenario | Rev% → true-up/Cost → GA GP → 总 GP 与锁定说明 | 至少留约 3s，不从零滚动数字，不裁掉 LE 仍未解决的影响 |
| 任务流转 | 弹窗内链路/最新日志；关窗后看板跨列位移 | 状态更新后展示反馈，再关窗保留约 1s，让 520ms 跨列动画落位；只有界面实际记录的状态才能剪入 |

不要让字幕和指针遮住上述强调区域。弹窗内容较长时分成“上半部链路”和“下半部日志”两个清楚的取景，而非边快速滚动边朗读。

## 6. 旁白、字幕与屏幕标注

### 6.1 旁白处理

1. 先按脚本逐段试读，记录每段实际时长；英文缩写和界面词会增加停顿。
2. 先做临时旁白辅助粗剪，确认镜头有足够操作和阅读时间；再录正式旁白。
3. 每段独立录制，前后留静音余量；保留原录音，剪除明显口误和冗长停顿。
4. 若某镜头超时，先删除重复旁白、完整键入和次要配置画面；必要时在章节间调剂秒数，不压缩证据可读性或强行加速声音。
5. 粗剪即按 170 秒控制。试读后可使用预留余量，但最终文件必须小于 180 秒；不能把音乐尾奏或额外片头另算。

建议统一读法：FP&A“财务规划与分析”；GP“毛利”；Rev%“收入占比”；true-up“季度轧差”；Segment“分摊维度”；Reference“参考号”。完整凭证号与账号留在画面，不必逐位朗读。

### 6.2 字幕与标注

- 中文字幕跟随旁白断句，一般每行约 16–24 个汉字、最多两行，预留左右与底部边距；这是本片排版起点，试播后按可读性调整。
- 字幕放在不遮挡 KPI、凭证或任务按钮的位置；必要时用独立底部字幕区，而不是覆盖表格合计。
- 同时仅保留一个解释性标注，例如 Base only 或 Total GP unchanged；避免与原生细框多重争抢注意力。
- 财务负号、百分号、USD、Original/Candidate 必须保留；不能把 LE 的负 GP 裁掉后只展示 GA 转正。
- 英文 UI 保持原文，不通过剪辑改写真实按钮、增加不存在的页面或伪造调用成功提示。
- 引用镜头保留 Business Logic.md、段落标题和规则原文，让来源可辨认。
- 每个章节的短标题占用原定镜头时长，不再额外加一长段开场。

## 7. 剪辑节奏与声音

- 以清楚的切镜头为主。章节之间可用 200–300ms 淡切；界面内保留原生动效，不再叠加明显弹跳、旋转或粒子效果。
- 放大前先用全景建立位置；每次只追踪一个关注点，镜头到位后停稳再讲数值。
- 可以剪短键入和无操作的等待，不剪断四步调查的逻辑，也不把剪辑后的速度写成产品性能承诺。
- 保留关键结果 2–3 秒可读时间；Source、Scenario 和任务状态回报是主要停顿点。
- 旁白优先，音乐与音效可省略；使用时保持持续低音量，点击提示不必每次都有声音。
- 输出前检查耳机和普通扬声器都能听清缩写、负数与“总毛利不变”等关键结论。

## 7A. 三分钟内的剪辑优先级

| 必须保留 | 可缩短或移出本片 |
| --- | --- |
| GA 异常与 LE 关联线索 | 完整输入/复制粘贴过程、重复页面定位 |
| 四步调查与凭证证据 | 逐项念出凭证号、账号与所有字段 |
| Base only、前两月锁定、总 GP 不变、LE 待复核 | 逐个解释每个 Segment 与所有成本列 |
| 一段真实流式输出及一次原文引用 | 全部回答等待时间、逐段阅读所有来源 |
| GP 图/阈值、趋势图/布局、模板入口 | 个人库创建/编辑、模板安装/保存/JSON 导出 |
| 同一 proposal 创建任务、角色切换、状态回报、完成记录 | 重复日志逐条朗读、逐个介绍五个内置 Sample |

片头/收尾各按现有 8 秒/7 秒预算执行；章节名称叠在当前画面，不增加独立过场。操作可以分段录制后硬切衔接，但不能跨用不同方案或任务编号。片尾原型说明与最后一句旁白同时呈现至少 5 秒。

## 9. 成片验收与修正原则

| 维度 | 通过条件 |
| --- | --- |
| 时长 | 实际成片小于 180 秒，目标 170 秒；含片头、片尾、转场、静音尾帧与音频尾部，不只检查脚本文字预算 |
| 故事完整 | 四条故事线均有可见操作和结果；任务明确从主案例的 saved proposal 创建 |
| 事实准确 | 脚本事实表中的范围、凭证、Reference、金额、Rev% 与实录一致 |
| 财务含义 | 前两月锁定、仅调整 base、总 GP 不变、LE 待复核均清楚表达 |
| 证据完整 | 不把“本次范围内未确认抵销”剪成“全系统没有正向凭证”；账号不被当作手工账证明 |
| 时间口径 | Month 3 主调查与季度累计 GP 图清楚区分；五季度趋势保留合成样例标记 |
| 任务含义 | 视角切换可见，状态由演示负责人回报；Completed 不被表述为凭证修正或系统问题已解决 |
| 演示边界 | 原型/样例/模拟提示可见；不声称真实 LLM、任意 SQL、生产财务数据、消息通知或共享市场已接入 |
| 可读性 | 1080p 实际播放时表格关键数值、来源标题、任务状态和字幕均能读清 |
| 连续性 | 无错页、重复创建、剪辑前后状态矛盾、无效点击或突然跳过关键结果 |
| 音画 | 无黑帧/闪屏、无爆音，旁白与当前功能/标注一致 |
| 版本 | 影片对应确认后的脚本与 Vantage 源版本；main 不被修改 |

先看一遍无声版，确认只看画面也能理解操作和结果；再只听旁白，确认没有把样例描述成已上线能力；最后正常播放做综合审阅。
