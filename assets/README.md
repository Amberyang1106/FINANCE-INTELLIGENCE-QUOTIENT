# Brand asset

lenovo-logo-red.png is the original horizontal red Lenovo logo from Lenovo Brand World. It is displayed without recoloring or changing its proportions.

- Brand guidance: https://brandworld.lenovo.com/visual-identity/logo/
- Asset: https://media.lenovobrandworld.fiestic.com/2022/06/08010946/LenovoLogo_POS-Red-H.png

Downloaded 2026-10-28 for the user-requested local Lenovo finance demo.

## Vantage typography
